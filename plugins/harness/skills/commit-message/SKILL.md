# コミットメッセージの作り方

1. `git diff --staged`（何もステージされていなければ `git diff`）で変更を確認する。
2. 次の形式で書く。

```
<種類>: <何をしたかを 50 文字以内で>

<なぜ変えたか。必要なときだけ、数行で>
```

- 種類は `feat` `fix` `docs` `refactor` `test` `chore` のいずれか。
- 1 行目は日本語で、文末に句点を付けない。
- 無関係な変更が混ざっていれば、コミットを分けるよう提案する。
